#### Mitchell Bike Co.

I chose a bike shop because I love cycling. It also shows how I think about AI adoption. I find it most useful to start with a workflow people already know, then ask where an AI agent can help and which decisions belong to people.

When a rider's gears skip under load, the agent uses the mechanic's observations and the bike's service history to diagnose the issue. It checks which parts fit the rider's upgraded wheels and prepares a quote. The mechanic reviews and sends every message, and only the customer can approve the repair.

- [Try the live demo](https://mitchell-bike-co.fly.dev/): work through a repair with the AI agent as the mechanic, then switch to the customer's view to review the quote.
- [Explore the code and evals](https://github.com/jmdev5313/Mitchell-Bike-Co#what-the-evals-found): see how a race-day repair exposed a missing parts check and changed the date the shop could promise.
